# Friction log

## 1. A distribution is not yet a decision output

The initial build could derive single-endpoint durations and summarize them but
could not locate a target estimate or compute threshold frequencies. The first
analytical slice now supplies multi-terminal derivation, `locate`, and
`threshold`; this item is retained as the provenance for that design change.

## 2. Competing terminal states matter

Completion and termination are both observed terminal events. A duration
distribution that silently includes only completed deals selects on outcome;
one that mixes them without showing terminal state answers a different
question. Analysis needs stratification or a competing-risks view.

## 3. Cohort completeness is distinct from observation coverage

All registered pilot cases can have observed durations while the enumeration of
qualifying acquisitions is still incomplete. Flyvbjerg represents metric
coverage, but not yet confidence that the case-finding frame is exhaustive.

## 4. Wikipedia is unusually effective for basic chronology

Dedicated transaction and company pages commonly state announcement,
completion or termination, value, parties, and regulatory history. This is
enough for a transparent pilot. Silence still cannot support non-occurrence.

## 5. Announcement value has vintages

Stock transactions change value between announcement and close. Eligibility
must use announced consideration; realized value is a different metric.

## 6. Calendar quantiles are required

Min/median/max/mean are insufficient for planning reserves. A decision-maker
needs empirical quantiles, threshold frequencies, and clear small-sample rules.

## 7. Dependence cannot default to case count

The initial unclustered analysis reported ten clusters for ten cases. The
revised package reports dependence as unassessed and leaves cluster count null.
Deals still require a substantive dependence assessment before cluster-aware
inference.
