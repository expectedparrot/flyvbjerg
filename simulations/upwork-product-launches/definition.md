# Draft definition

## Candidate unit

One named customer-facing product or feature introduced by Upwork.

This definition is not yet adequate. Upwork's disclosures mix:

- persistent products (`Upwork Chat Pro`);
- umbrella technologies (`Uma`);
- marketplace destinations (`AI Services hub`);
- small features (`Proposal Tips`);
- commercial mechanisms (`Boosted Profiles`); and
- release events containing several products (`Upwork Updates: Spring 2024`).

## Provisional inclusion criteria

- Named by Upwork in a public primary source.
- Described as new, launched, introduced, premiered, or beginning rollout.
- Directly changes an Upwork client or freelancer experience.

## Provisional exclusions

- Research reports, corporate acquisitions, and internal-only technology.
- Third-party apps merely listed in a partnership catalog.
- A later enhancement when the underlying product is already represented;
  preserve it as a product event instead.

## No outcome definition yet

We should not call this a reference class until a common estimand can be applied
without treating selective company disclosures as comparable outcomes.
